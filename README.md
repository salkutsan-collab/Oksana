# Наклейки Panini - ЧМ-2026 (вторая копия)

Трекер наклеек Panini FIFA World Cup 2026 для отдельной компании.

- Отмечать, какие наклейки уже есть, какие нужны и какие дубли на обмен.
- 980 наклеек: вступление и «Музей ФИФА» + 48 сборных по 20 наклеек.
- Общая база: отметил на одном телефоне - видно на другом.
- Работает офлайн, ставится на телефон иконкой («Добавить на главный экран»).

Это независимая копия трекера. Программа та же, но комната в базе своя,
поэтому отметки никак не пересекаются с первой копией.

Открыть: `index.html`.
